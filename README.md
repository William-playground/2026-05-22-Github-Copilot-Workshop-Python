## 1.pomodoro — ゲーミフィケーション対応ポモドーロタイマー

集中セッションを完了するたびに XP を獲得し、レベルアップ・バッジ獲得・連続日数（ストリーク）・週間/月間統計を楽しめる Flask 製の Web アプリです。

### 起動方法

```bash
cd 1.pomodoro
pip install -r requirements.txt
python app.py
```

ブラウザで <http://127.0.0.1:5000/> を開いてください。

### テスト

```bash
cd 1.pomodoro
python -m pytest
```

### 主な機能

- 25 / 5 / 15 分のタイマー（作業 / 小休憩 / 長休憩）
- 完了ごとに +25 XP、しきい値到達でレベルアップ
- 達成バッジ（初回、累計、ストリーク、週間回数、レベル到達）
- 連続日数（現在 / 最長）の表示
- 週間 / 月間の完了数・完了率・平均集中時間・日別グラフ
