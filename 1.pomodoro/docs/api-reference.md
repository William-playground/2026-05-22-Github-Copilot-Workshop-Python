# API リファレンス

## 概要

ポモドーロタイマーアプリケーションの REST API リファレンスです。

## エンドポイント一覧

### GET /

メインページを返します。

**リクエスト**

```
GET /
```

**レスポンス**

- ステータスコード: `200 OK`
- Content-Type: `text/html`
- ボディ: `templates/index.html` をレンダリングしたHTMLページ

**説明**

アプリケーションのメインページ（ポモドーロタイマー画面）を返します。ページには `static/css/style.css` と `static/js/timer.js` が読み込まれます。

---

> **備考**: 現在の実装では REST API エンドポイントは `/` のみです。タイマーのロジックはフロントエンド（JavaScript）で完結しており、サーバーサイドの API は存在しません。
